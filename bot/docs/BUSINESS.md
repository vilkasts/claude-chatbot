# Clientsy — справочник по роли «Владелец бизнеса»

> Этот документ — база знаний бота-помощника по настройке приложения **Clientsy** для пользователей с активной ролью **Владелец бизнеса**.
> Источник: компонент «Помощь» приложения Clientsy (`src/widgets/business/help/data/faq-items-business.ts`) + русские локали (`locales/ru/*.json`).

---

## 0. Контекст приложения

**Clientsy** — приложение онлайн-записи для салонов и частных мастеров. У одного пользователя может быть до трёх ролей одновременно: **Владелец бизнеса**, **Сотрудник**, **Клиент**. Этот справочник покрывает только роль **Владелец бизнеса**.

Доступные разделы у владельца бизнеса:

| Раздел            | Иконка (lucide)                         | Где находится                                               |
| ----------------- | --------------------------------------- | ----------------------------------------------------------- |
| Управление        | `BriefcaseBusinessIcon` (кейс 💼)       | Главный таб владельца — точка входа в большинство сценариев |
| Записи            | `CalendarDays` (📅)                     | Отдельный таб в нижней навигации                            |
| Клиенты           | `Users2` (двое людей 👥)                | Отдельный таб в нижней навигации                            |
| Профиль (бизнеса) | `Building2` (🏢)                        | Внутри **Управления**                                       |
| Услуги            | `ClipboardList` (планшет со списком 📋) | Внутри **Управления**                                       |
| Команда           | `Users` (👥)                            | Внутри **Управления**                                       |
| Аналитика         | `BarChart3` (столбики 📊)               | Внутри **Управления**                                       |
| Подписка          | `CreditCard` (💳)                       | Внутри **Управления**                                       |
| Настройки         | `Settings` (шестерёнка ⚙️)              | Внутри **Управления**                                       |

## 1. Глоссарий иконок и базовых элементов

Когда в инструкции встречается «нажмите кнопку с иконкой …», имеется в виду следующее:

| Иконка (lucide) | Визуал | Что значит / как описать пользователю                                                                                |
| --------------- | ------ | -------------------------------------------------------------------------------------------------------------------- |
| `Plus`          | ➕     | «Кнопка с плюсом» — добавить / создать новый элемент. Часто это круглая FAB в углу. Лейбл по умолчанию — «Добавить». |
| `Pen`           | ✏️     | «Кнопка с карандашом» — редактировать. Иногда без подписи, рядом с заголовком. Лейбл — «Редактировать».              |
| `Trash2`        | 🗑️     | «Круглая кнопка с иконкой корзины» — удалить. Обычно появляется в режиме редактирования.                             |
| `ExternalLink`  | ↗️     | «Поделиться» / «Открыть ссылку». Для онлайн-записи.                                                                  |
| `ToggleLeft`    | 🔘     | Переключатель «Активен / Неактивен» (для бизнеса и сотрудников).                                                     |
| `CircleAlert`   | ⚠️     | Иконка предупреждения — отмечает раздел **«Удаление данных»** в Настройках.                                          |
| `Ban`           | 🚫     | «Заблокировать» (для клиентов).                                                                                      |
| `User`          | 👤     | Один человек — раздел **«Роль»** в настройках.                                                                       |
| `Settings`      | ⚙️     | Шестерёнка — **Настройки**.                                                                                          |
| `Headset`       | 🎧     | Поддержка / помощь.                                                                                                  |
| `CreditCard`    | 💳     | **Подписка** / оплата.                                                                                               |

Обозначения путей в этом документе:

- Путь записывается через стрелку `→`, например: `Управление → Услуги → ➕ Добавить`.
- В скобках после названия может стоять иконка/тип элемента, если без этого его трудно найти.
- Конкретные значения в кавычках («Назначить», «Редактировать») — это надписи на кнопках/вкладках **ровно так, как они написаны в интерфейсе**.

## 2. FAQ — вопросы и ответы

### 2.1. Начало работы

#### ❓ Как начать принимать записи?

**Ответ:** Чтобы клиенты могли записываться, выполните 3 шага:

1. **Создайте хотя бы одну услугу** в разделе «Услуги».
   **Путь:** `Управление → Услуги → ➕ Добавить`
2. **Настройте рабочий график сотрудника** в его профиле (вкладка «Рабочая область»).
   **Путь:** `Управление → Команда → выбрать сотрудника → «Рабочий график» → «Настроить»`
3. **Назначьте услуги сотруднику** в его профиле (вкладка «Услуги»).
   **Путь:** `Управление → Команда → выбрать сотрудника → «Услуги» → «Назначить»`

---

### 2.2. Профиль бизнеса

#### ❓ Как заполнить профиль бизнеса?

**Ответ:** В профиле бизнеса можно настроить внешний вид и добавить информацию о вашем бизнесе.

1. **Установите аватарку** — нажмите на иконку карандаша (`Pen` ✏️) рядом с фото.
   **Путь:** `Управление → Профиль → ✏️ (карандаш у фото)`
2. **Укажите название, номер телефона, адрес и ссылку на Instagram.**
   **Путь:** `Управление → Профиль → «Редактировать»`

---

#### ❓ Можно ли изменить регион, часовой пояс или валюту?

**Ответ:** Регион, часовой пояс и валюта задаются при создании бизнеса и **не могут быть изменены в дальнейшем**. Если эти данные нужно скорректировать — удалите профиль и создайте бизнес заново.

1. **Удалить бизнес и создать новый.**
   **Путь:** `Управление → Настройки → ⚠️ «Удаление данных» → «Удаление профиля бизнеса»`

---

#### ❓ Как поделиться ссылкой для записи?

**Ответ:** Есть два вида ссылок для записи — общая ссылка вашего заведения и персональная ссылка мастера.

1. **Ссылка на бизнес** — клиент сам выберет удобного сотрудника и услугу.
   **Путь:** `Управление → Профиль → «Ссылка для онлайн-записи» → ↗️ Поделиться`
2. **Ссылка на сотрудника** — подойдёт, если хотите направить клиента к конкретному мастеру или на определённую услугу.
   **Путь:** `Управление → Команда → выбрать сотрудника → «Ссылка для онлайн-записи» → ↗️ Поделиться`

---

#### ❓ Как деактивировать профиль бизнеса?

**Ответ:** Деактивируйте профиль, если временно не оказываете услуги. Пока профиль вашего бизнеса неактивен, клиенты не смогут записаться к вам через приложение или по ссылке.

**Путь:** `Управление → Профиль → «Редактировать» → переключатель «Активен»`

---

### 2.3. Услуги

#### ❓ Как создать услугу?

**Ответ:** Перейдите в раздел «Услуги». Укажите название, цену, длительность и описание. Вы также можете выбрать цвет для отображения в календаре и сразу назначить сотрудников.

**Путь:** `Управление → Услуги → ➕ Добавить`

---

#### ❓ Как удалить услугу?

**Ответ:** Кнопка удаления находится в редактировании услуги — **круглая кнопка с иконкой корзины** (`Trash2` 🗑️).

**Путь:** `Управление → Услуги → выбрать услугу → «Редактировать» → 🗑️`

---

### 2.4. Команда (сотрудники)

#### ❓ Как пригласить сотрудника в команду?

**Ответ:** Перейдите в раздел «Команда». Скопируйте ссылку-приглашение и отправьте сотруднику. По ссылке могут зарегистрироваться несколько человек. **Ссылка действительна до конца текущего дня.**

**Путь:** `Управление → Команда → «Добавить»`

---

#### ❓ Как редактировать данные сотрудника?

**Ответ:** Возможности редактирования зависят от того, кто является сотрудником в вашем бизнесе.

1. **Вы сами работаете в своём бизнесе** — переключитесь на роль «Сотрудник» и самостоятельно измените имя, фамилию, аватарку и телефон в своём профиле.
   **Путь:** `Управление → Настройки → 👤 «Роль» → «Сотрудник»`
2. **У вас есть наёмные сотрудники** — как владелец вы можете только активировать или деактивировать сотрудника и указать его должность. Имя, аватарку и контакты каждый сотрудник меняет сам, войдя через роль «Сотрудник».
   **Путь:** `Управление → Команда → выбрать сотрудника → «Редактировать»`

---

#### ❓ Как настроить рабочий график сотрудника?

**Ответ:** Выберите сотрудника в разделе «Команда». Вы можете настроить **гибкий** либо **постоянный** график работы. Отметьте рабочие дни, время начала и окончания, а также перерывы.

**Путь:** `Управление → Команда → выбрать сотрудника → «Рабочий график» → «Настроить»`

---

#### ❓ Как назначить услуги сотруднику?

**Ответ:** Назначить услуги сотруднику можно 2 способами:

1. Выберите сотрудника в разделе «Команда». Переключитесь на вкладку «Услуги» в профиле сотрудника и нажмите «Назначить». Выберите нужные услуги из списка и примените.
   **Путь:** `Управление → Команда → выбрать сотрудника → «Услуги» → «Назначить»`
2. Перейдите в раздел «Услуги». Выберите услугу и переключитесь на вкладку «Сотрудники». Нажмите «Назначить» и выберите сотрудников из списка.
   **Путь:** `Управление → Услуги → выбрать услугу → «Сотрудники» → «Назначить»`

---

#### ❓ Как добавить выходной или отпуск сотруднику?

**Ответ:** Перейдите в раздел «Команда». Выберите причину (выходной, отпуск, больничный), дату и при необходимости время.

**Путь:** `Управление → Команда → выбрать сотрудника → «Отпуска и выходные» → «Добавить»`

---

#### ❓ Как деактивировать профиль сотрудника?

**Ответ:** Деактивируйте сотрудника, если он временно не работает или больше не оказывает услуги. Пока профиль сотрудника неактивен, клиенты не смогут записаться к нему через приложение или по ссылке.

**Путь:** `Управление → Команда → выбрать сотрудника → «Редактировать» → переключатель «Активен»`

---

#### ❓ Как удалить сотрудника?

**Ответ:** Кнопка удаления находится в редактировании профиля сотрудника — **круглая кнопка с иконкой корзины** (`Trash2` 🗑️).

**Путь:** `Управление → Команда → выбрать сотрудника → «Редактировать» → 🗑️`

---

#### ❓ Почему нельзя удалить себя из сотрудников?

**Ответ:** Если вы одновременно являетесь владельцем бизнеса **и** его сотрудником — удалить себя из команды невозможно. Вместо этого вы можете деактивировать свой профиль сотрудника. После этого вы перестанете отображаться у клиентов как специалист и запись к вам будет недоступна.

**Путь:** `Управление → Команда → выбрать себя → «Редактировать» → переключатель «Активен»`

---

### 2.5. Клиенты

#### ❓ Как добавить нового клиента?

**Ответ:** Клиент может попасть в ваш список двумя способами:

1. **Клиент самостоятельно записывается** на ваши услуги через ссылку для онлайн-записи — он автоматически появится в списке клиентов.
   **Путь:** `Управление → Профиль → ↗️ Поделиться` (отправить клиенту ссылку)
2. **Вы добавляете клиента вручную** в разделе «Клиенты».
   **Путь:** `Клиенты → ➕ Добавить`

---

#### ❓ Как редактировать данные клиента?

**Ответ:** Вы можете уточнить имя и фамилию клиента, а также добавить личные заметки — они **видны только вам** и не отображаются у клиента. Фото профиля и номер телефона клиент устанавливает самостоятельно в своём профиле.

**Путь:** `Клиенты → выбрать клиента → «Редактировать»`

---

#### ❓ Как заблокировать клиента?

**Ответ:** Клиент будет добавлен в чёрный список и не сможет записываться на услуги. Разблокировать можно в любой момент.

**Путь:** `Клиенты → выбрать клиента → 🚫 «Заблокировать»`

---

#### ❓ Как удалить клиента?

**Ответ:** Кнопка удаления находится в редактировании профиля клиента — **круглая кнопка с иконкой корзины** (`Trash2` 🗑️).

**Путь:** `Клиенты → выбрать клиента → «Редактировать» → 🗑️`

---

### 2.6. Записи (визиты)

#### ❓ Как назначить визит клиенту?

**Ответ:** Назначить визит клиенту можно 2 способами:

1. Перейдите в раздел «Клиенты». Выберите клиента из списка. Нажмите кнопку «Назначить визит».
   **Путь:** `Клиенты → выбрать клиента → «Назначить визит»`
2. Перейдите в раздел «Записи». Нажмите кнопку «➕» и выберите «Назначить визит». Выберите клиента и подходящую ему услугу, мастера и время.
   **Путь:** `Записи → ➕ → «Назначить визит» → выбрать клиента`

---

#### ❓ Как перекрыть время в календаре?

**Ответ:** Используйте эту опцию, если нужно временно закрыть слот в расписании — например, если сотрудник отлучается по личным делам. Укажите сотрудника, причину, дату и время.

**Путь:** `Записи → ➕ → «Перекрыть время» → выбрать сотрудника`

---

#### ❓ Как посмотреть детали визита клиента?

**Ответ:** Найти нужную запись можно двумя способами:

1. **Через список клиентов** — откройте профиль клиента, чтобы увидеть все его предстоящие и прошлые визиты.
   **Путь:** `Клиенты → выбрать клиента`
2. **Через календарь** — найдите запись по дате и времени и нажмите на неё.
   **Путь:** `Записи → выбрать запись`

📝 **Примечание:** В деталях записи — контакты клиента, кнопка для перехода в чат, а также возможность отметить неявку или отменить запись.

---

### 2.7. Подписка и оплата

#### ❓ Как работает подписка и оплата?

**Ответ:** После регистрации бизнеса автоматически запускается **30-дневный пробный период** с полным доступом ко всем функциям без ограничений.

1. По истечении пробного периода **выберите тарифный план** в зависимости от количества сотрудников в вашем заведении.
   **Путь:** `Управление → 💳 Подписка → выбрать тарифный план`
2. После выбора плана вы будете перенаправлены на **веб-сайт Clientsy**, где можно оплатить подписку одним из доступных способов.

📝 **Примечание:** Отмена подписки доступна в любой момент.

**Доступные планы (для справки):**

| План            | Описание                                 |
| --------------- | ---------------------------------------- |
| Бесплатный      | Для знакомства с сервисом                |
| Только я (Solo) | Для одного специалиста (без сотрудников) |
| Команда (Team)  | Для салонов с сотрудниками               |
| Про             | Без ограничений                          |

---

### 2.8. Аналитика

#### ❓ Как посмотреть аналитику?

**Ответ:** Перейдите в раздел «Аналитика». Выберите период (сегодня, неделя, месяц или произвольный). Вы увидите выручку, количество записей, отмены, неявки, топ услуг и статистику по сотрудникам.

**Путь:** `Управление → 📊 Аналитика`

---

### 2.9. Настройки и роли

#### ❓ Как сменить тему, язык или роль?

**Ответ:** Настройте приложение под себя — выберите удобный язык, тему оформления и переключайтесь между ролями.

**Путь:** `Управление → ⚙️ Настройки`

Доступные настройки:

- **Роль** — Владелец бизнеса / Сотрудник / Клиент.
- **Язык** — Русский / Беларуская.
- **Тема** — Светлая / Тёмная.
- **Удаление данных** (раздел ⚠️ «Удаление данных»).

---

#### ❓ Не вижу нужного раздела — что делать?

**Ответ:** Доступные разделы зависят от выбранной роли. Если вы не находите нужный функционал — скорее всего, активна другая роль.

- **«Владелец бизнеса»** — управляйте заведением: создавайте услуги, добавляйте сотрудников, отслеживайте записи и аналитику.
- **«Сотрудник»** — просматривайте своё расписание и записи клиентов, если вы работаете в чьём-то заведении.
- **«Клиент»** — записывайтесь на услуги к мастерам и бизнесам, управляйте своими визитами.

📝 **Переключить роль:** `Управление → ⚙️ Настройки → 👤 Роль`

---

### 2.10. Удаление данных и поддержка

#### ❓ Как удалить свои данные?

**Ответ:** Вы можете удалить данные бизнеса или полностью стереть все свои данные из приложения.

1. **Удаление профиля бизнеса** — удаляет только данные заведения. Остальные роли (сотрудник, клиент) и аккаунт сохранятся.
   **Путь:** `Управление → ⚙️ Настройки → ⚠️ «Удаление данных» → «Удаление профиля бизнеса»`
2. **Удаление аккаунта** — удаляет все ваши роли и данные **без возможности восстановления**.
   **Путь:** `Управление → ⚙️ Настройки → ⚠️ «Удаление данных» → «Удаление всего аккаунта»`

⚠️ Для подтверждения удаления нужно ввести ключевое слово «Удалить».

---

#### ❓ Что делать, если что-то не работает?

**Ответ:** Если вы столкнулись с ошибкой или настройки не дают нужного результата — напишите нам. Команда разработчиков на связи и поможет разобраться. Используйте кнопку 🎧 в нижнем углу страницы «Помощь», чтобы открыть чат с ботом поддержки.

## 4. Подсказки для бота-помощника

- Если пользователь спрашивает «как сделать X», и X относится к настройке бизнеса — найдите ближайший FAQ-пункт и дайте **пошаговую инструкцию с путём** в формате `Раздел → Подраздел → Кнопка`.
- Если у действия есть **иконка без подписи** (✏️ редактировать у фото, 🗑️ удалить, ➕ добавить) — обязательно упомяните иконку, иначе пользователю её не найти.
- Если у вопроса нет ответа в этом документе — честно скажите «В документации Clientsy я этого не нашёл» и предложите написать в поддержку (кнопка 🎧 на странице «Помощь»).
- Региональные настройки (страна, валюта, часовой пояс) **нельзя поменять** после создания бизнеса — только пересоздать профиль.
- Удалить себя из команды нельзя, если вы одновременно владелец и сотрудник — только деактивировать.
- Ссылка-приглашение для сотрудников действует **до конца текущего дня**.
- Пробный период подписки — **30 дней** с полным доступом.
